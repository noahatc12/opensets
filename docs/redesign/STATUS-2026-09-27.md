## Traps this build hit, so the next one does not

- A gesture layer must ship with "old interactions still work" checks: `touch-action:
  pan-y` on a container silently killed every horizontal scroller inside it.
- Device-only layout bugs: ask Safari or Home Screen first, then get the `?probe`
  screenshot, before theorising from pixels. Two deploys went to the wrong theory.
- A text glyph never centres in a sized control; draw icons as SVG strokes.
- `npm run build` piped through grep hides a failed typecheck; chain with `|| exit 1`.
