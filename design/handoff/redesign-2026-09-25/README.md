# Redesign handoff (Claude Design, 2026-09-25)

`OpenSets Redesign.dc.html` is Noah's full-app redesign prototype, exported from the Claude Design
project "App redesign planning" (`3a85f014-dbba-465e-8430-df8c4ef3b600`). `support.js` is the
prototype's runtime (generated by Claude Design; it loads React 18 UMD from unpkg at boot).

This folder is the design source of truth for the `redesign/editorial` port. The plan and the
coverage ledger are in `docs/redesign/PLAN.md`. The reference screenshots the port is checked
against are in `design/redesign-ref/` and are regenerated with:

```
# from the repo root; the html resolves its mono font relative to itself, so serve a folder
# that also contains src/styles/fonts/JetBrainsMono-Variable.woff2 (a scratch copy works)
python -m http.server 8766 -d <folder-with-index.html-and-support.js>
REF_BASE=http://localhost:8766/index.html REF_OUT=design/redesign-ref node scripts/ref-capture.mjs
REF_BASE=http://localhost:8766/index.html REF_OUT=design/redesign-ref node scripts/ref-capture-fresh.mjs
```

Known quirks of the prototype, not bugs in the port:
- Archivo loads from Google Fonts here; the port self-hosts it (fontsource, OFL).
- Prop overrides (`__dcSetProps`) crash its runtime, which is why the fresh-user states are
  captured through its own "Erase all data" flow.
- It uses a 30-lift catalog, one progression rule, localStorage and generated sample data. The
  table "Where the prototype lies" in the plan says what the port does instead.
